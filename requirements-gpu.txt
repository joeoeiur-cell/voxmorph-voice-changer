# Neural identity voices (RVC). Install AFTER requirements.txt.
#
# ---------------------------------------------------------------------------
# READ THIS FIRST — the RVC ecosystem has a hard Python ceiling.
#
# rvc-python 0.1.5 (the last release, Oct 2024) pins:
#       numpy <= 1.23.5
#       fairseq == 0.12.2
#       faiss-cpu == 1.7.3
#
# numpy 1.23.5 has no wheels above Python 3.11, and fairseq 0.12.2 does not
# build on modern toolchains. In practice that means identity voices require a
# DEDICATED Python 3.10 or 3.11 environment. They cannot share the same
# interpreter as the packaged app, which targets 3.12.
#
# This is why the shipped installer is DSP-only: the character presets need
# none of this, run on any CPU, and keep the download near 180 MB.
# ---------------------------------------------------------------------------
#
# Recommended setup for identity voices:
#
#   py -3.10 -m venv .venv-rvc
#   .venv-rvc\Scripts\activate
#   pip install "numpy<=1.23.5"
#   pip install torch==2.1.2+cu118 torchaudio==2.1.2+cu118 \
#       --index-url https://download.pytorch.org/whl/cu118
#   pip install -r requirements-gpu.txt
#   python run.py
#
# AMD / Intel GPU on Windows:  pip install torch-directml
# CPU only: works, but expect 300 ms+ latency — prefer the DSP presets.

-r requirements.txt
